# Knowledge Base — The Scoring Method

Base de conocimiento extraída del curso completo de **Will Robins**
(82 video lessons transcritos, ~560KB de contenido analizado).

## Cómo usar este KB

Al arrancar una sesión sobre la golf-app, cargar:

1. **`00_method_overview.md`** — filosofía + conceptos clave (siempre)
2. **`01_concepts_by_module.md`** — qué enseña cada módulo del curso
3. **`02_schema_mapping.md`** — qué del método ya está en el schema vs. falta
4. **`03_gaps.md`** — gaps críticos con propuesta de modelo Prisma
5. **`04_roadmap.md`** — features priorizadas P0/P1/P2
6. **`05_drills_catalog.md`** — todos los drills con parámetros exactos
7. **`06_journaling_prompts.md`** — preguntas/reflexiones a capturar

## Workflow propuesto

**En cada sesión de trabajo sobre golf-app:**

```
1. Leer 00_method_overview.md + 02_schema_mapping.md (5 min)
2. Identificar qué feature de 04_roadmap.md trabajamos hoy
3. Implementar: schema → API → UI
4. Validar contra 05_drills_catalog.md o 06_journaling_prompts.md
5. Marcar feature como ✅ en 04_roadmap.md
```
